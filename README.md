# Business KPI Dashboard

An interactive business analytics dashboard built with Python and Streamlit for exploring sales, revenue, products, cities and payment patterns.

## Dashboard Features

- Revenue KPI
- Order count
- Units sold
- Average order value
- Category revenue
- Monthly revenue trend
- City performance
- Payment method distribution
- Top product table
- Interactive category and city filters
- Filtered CSV download

## Technology

**Python | Streamlit | Pandas | Plotly | CSV | Data Visualization**

## Files

| File | Purpose |
|---|---|
| `app.py` | Streamlit dashboard |
| `data_processing.py` | Data validation and preparation |
| `kpi_analysis.py` | KPI and performance calculations |
| `business_data.csv` | Sample business dataset |
| `requirements.txt` | Python dependencies |
| `README.md` | Project documentation |

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the dashboard:

```bash
streamlit run app.py
```

The dashboard opens in your browser and provides interactive filters and charts.

## Portfolio Focus

This project demonstrates practical dashboard development, KPI calculation, data processing, interactive filtering and business-oriented data visualization.
